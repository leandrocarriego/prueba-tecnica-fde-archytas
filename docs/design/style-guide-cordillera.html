Principios
Las reglas que deciden cuándo usar cada cosa.
Ante la duda, avisa
Ningún número se calcula con datos sin confirmar. Lo dudoso se muestra aparte con su acción para resolverlo.
Una sola acción llena
Por pantalla hay un único botón con el acento; el resto es contorno o enlace. El color naranja significa “decidí acá”.
La plata siempre en mono tabular
Montos, fechas y códigos usan IBM Plex Mono con cifras tabulares para que las columnas se lean de un golpe.
Lo que no se puede ver, no aparece
Los permisos se resuelven ocultando el ítem del menú, no mostrando un botón que devuelve error.
